# Incoming document population

Synthetic source-quality summary. Service: document-verification.

The v2.2 evaluation window and v2.3 evaluation window each contain 1,000 labeled
documents. Each window has 700 high-resolution and 300 low-resolution scans.
Country mix, language mix and mean source resolution are stable by stratum.
Labels were produced by the same synthetic labeling policy in both windows.

This comparison rules against a large change in category mix, but cannot exclude
every unmeasured distribution shift. Review subgroup errors and changed code.
